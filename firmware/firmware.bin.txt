PLACEHOLDER - Ganti file ini dengan firmware.bin hasil build PlatformIO.

Langkah:
1. Build project di PlatformIO
2. Ambil file dari: .pio/build/esp32doit-devkit-v1/firmware.bin
3. Timpa file ini dengan firmware.bin tersebut
4. Update version di firmware/version.json
5. git add . && git commit -m "Update firmware vX.X.X" && git push
